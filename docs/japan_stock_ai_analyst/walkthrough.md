# 日本株AIアナリスト・エクイティリサーチ自動運用システム 完成報告 (Walkthrough)

日経平均・TOPIX・ドル円為替および主要個別銘柄のマーケットデータを完全無料で自動収集し、Google Gemini がシニア株式アナリスト水準の詳細なリサーチレポートを毎日自動執筆して、収益化対応Webサイト（GitHub Pages）への自動公開とスマホ通知を行うシステムが完成しました。

---

## 🎯 実装したコンポーネント一覧

| ファイル | 役割 | 特徴 |
| :--- | :--- | :--- |
| **`collector.py`** | 日本株・主要指標データ収集 | `yfinance` を活用し、完全無料・APIキー不要で日経平均、TOPIX、ドル円、米国株、主要個別株を取得。RSI(14)、SMA(5/25/75)、MACD、ボリンジャーバンド(±2σ)を自動算出。 |
| **`analyst.py`** | Gemini AIアナリスト分析 | シニア・クオンツ・エクイティアナリストとして、マクロ要因、詳細テクニカル分析、明日以降の「メインシナリオ(60%)」「リスクシナリオ(40%)」を構造化して執筆。 |
| **`builder.py`** | 収益化対応Webサイト生成 | Tailwind CSSによる投資リサーチハウス風の美しいレスポンシブHTMLをビルド。Google AdSense広告枠、ネット証券（SBI・楽天）アフィリエイト枠、免責事項を自動配置。 |
| **`notifier.py`** | スマホ速報通知 | 大引け後に主要指数の騰落とレポート要約、Webサイト閲覧URLをDiscord Webhookでスマホにプッシュ通知。 |
| **`mcp_server.py`** | スマホGemini連携用MCPサーバー | スマホのGeminiアプリから「本日の日経平均の要約」「個別銘柄（7203等）のテクニカル分析」を対話形式で呼び出せるツールを提供。 |
| **`main.py`** | パイプライン統合実行 | データ収集 ➜ レポート生成 ➜ HTMLビルド ➜ スマホ通知の一連のフローを一括実行。 |
| **`.github/workflows/daily_report.yml`** | 完全自動化ワークフロー | 日本時間 平日15:45（東証大引け後）に自動起動し、完全無料で自動更新・コミット・プッシュ。 |
| **`README.md`** | 導入・運用マニュアル | 古いPCのブラウザから GitHub Codespaces を使って完全無料で運用開始するための手順書。 |

## 💰 収益化（マネタイズ）の仕組み

1. **Google AdSense（広告収入）**:
   - ヘッダー直下および記事フッター下に、レスポンシブ広告スロットを配置済み。審査通過後に広告タグを貼るだけで即座に収益化が可能。
2. **ネット証券アフィリエイト（超高単価成果報酬）**:
   - 記事直下に「テクニカル分析におすすめのネット証券（SBI証券、楽天証券）」の比較紹介カードを配置。A8.net等のASPリンクに差し替えるだけで、1件あたり数千円〜1万円以上の報酬を狙えます。
3. **投資関連書籍・ツール紹介**:
   - サイドバーにおすすめ教材・分析ツールの紹介枠を配置。

## 📱 古いPCから始める次のアクション

1. GitHubに新しいプライベートリポジトリを作成し、本プロジェクトのファイルを配置します。
2. リポジトリの **Settings ＞ Secrets** に `GEMINI_API_KEY`（[Google AI Studio](https://aistudio.google.com/) から無料取得）と `DISCORD_WEBHOOK_URL` を登録します。
3. **Settings ＞ Pages** でフォルダを `/docs` に設定して有効化します。
4. これで平日の夕方15:45に、手元のPCを立ち上げていなくてもクラウド上で勝手にレポートが更新・公開され、スマホに通知が届くようになります！
